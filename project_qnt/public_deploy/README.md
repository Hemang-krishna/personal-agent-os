## 📦 1-Click Deployment Instructions

### Deploy to Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` inside `/data/project_qnt/public_deploy/`

### Deploy to Cloudflare Pages
1. Go to Cloudflare Dashboard ──► Pages ──► Create Project
2. Upload this folder or connect the GitHub repository `Hemang-krishna/personal-agent-os`.

### Run Locally
```bash
python3 -m http.server 8080 --directory /data/project_qnt/public_deploy/
```
Open `http://localhost:8080` in your browser.
